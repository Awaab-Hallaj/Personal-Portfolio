1. Project Overview
This project is a personal portfolio website developed using HTML5 and CSS3. It introduces me, presents examples of my interests and coursework, and provides a contact form and also demonstrates semantic HTML elements, hyperlinks, navigation menus, images, embedded video, form controls, CSS styling, hover effects, floating layouts, and responsive design.
2. Website Pages
The website contains four HTML pages:
•	Home (index.html): Introduces me and provides links to the other website pages.
•	About Me (about-me.html): Provides personal information, displays a profile photograph, and includes an HTML5 video.
•	Projects (projects.html): Presents examples of projects and areas of coursework.
•	Contact (contact.html): Provides a form with name, email, telephone, and comments fields.
The navigation menu allows visitors to move between the pages.
3. Technologies Used
•	HTML5: Defines the structure and content of each page.
•	CSS3: Controls colours, typography, spacing, borders, layouts, and hover effects.
•	Media queries: Apply different CSS rules at different screen widths.
•	Git and GitHub: Provide version control and online source-code hosting.
•	GitHub Pages: Used to publish the website online.

5. Design and Styling
The website uses a purple colour palette with light backgrounds and darker text to keep the content readable and consistent.
The main stylesheet css/style.css, contains the general page styling, including the page background, font, header, navigation, content wrapper, project cards, profile image, form controls, and footer.
The header uses a CSS linear gradient. Navigation links have hover styling, and the selected page is identified using a CSS class.
The home page uses floated content boxes. The projects page uses repeated article elements with a consistent visual style.

6. Responsive Design
The website uses CSS media queries to adapt its layout to different screen widths.
•	Tablet: tablet.css applies its rules between 480px and 960px.
•	Mobile: mobile.css applies its rules at widths of 479px and below.
•	Desktop: desktop.css applies its rules at widths 961px and above

7. HTML Forms and Validation
The contact page contains labelled form controls for a visitor's name, email address, telephone number, and comments.
The form uses HTML attributes such as required, minlength, type="email", type="tel", and pattern to provide browser-based validation.
The form uses a mailto: action. It relies on the visitor having a suitable email.

8. Multimedia
The About Me page uses an image element with alternative text and an HTML5 video element.
The video includes the controls attribute so visitors can play, pause, and adjust playback using the browser's video controls. A poster image is specified using the poster attribute.

9. Version Control and Deployment
The source code is maintained in a Git repository and hosted on GitHub. The repository is intended to be public so the source code can be reviewed.
GitHub Pages is used to publish the static website from the repository's main branch and root directory.
